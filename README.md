# Clinic Equipment & Sterilization Tracker Backend

Environment-only NestJS backend scaffold. Application features have not been implemented.

## Start the development environment

Install dependencies:

```bash
npm install
```

Start PostgreSQL:

```bash
docker compose up -d
```

Stop PostgreSQL:

```bash
docker compose down
```

Check the container status:

```bash
docker compose ps
```

Start NestJS in development mode:

```bash
npm run start:dev
```
